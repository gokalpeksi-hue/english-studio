# English Studio

İngilizce kelime/cümle kartı uygulaması. Web ve telefonda çalışır.

## Özellikler
- **Excel / CSV yükle:** 1. kolon İngilizce, 2. kolon Türkçe olacak şekilde dosya yükleyince kartlar otomatik üretilir.
- **Karta tıkla → Türkçesi:** Kartın üzerine bir kez tıklayınca arka yüzünde Türkçe karşılığı çıkar.
- **Kelime/kalıp balonları:** Cümledeki kelimelere tıklayınca anlam, örnek cümle ve eş anlamlılar gösterilir.
- **Kaldığın yerden devam:** Uygulamayı her açtığında en son baktığın kartta başlar.
- **Kopyala (📋):** İngilizce cümlenin tamamını tek tıkla panoya kopyalar.
- **Seslendirme (🔊):** Cümleyi sesli okur.
- Yüklenen dosya tarayıcı hafızasında kalıcı tutulur; "🗑 Sıfırla" ile varsayılan listeye dönülür.

## Kullanım
1. `index.html` dosyasını aç (veya GitHub Pages adresinden gir).
2. "📂 Excel / CSV Yükle" ile kendi kelime listeni yükle.
3. Kartlarla çalış: tıkla → çevir, ← → ile gezin, kelimelere tıkla → anlam.
